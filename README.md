# Bifrost Design Assets

Bifrost brand, BNC and vETH logos, image exports, and downloadable asset packs.

- `brand/`: brand asset packages.
- `token_logo/`: token logos and downloadable packs.
- `app_icon/` and `img/`: application and campaign images.

The default branch remains `master`; all existing asset paths are preserved. The previous repository names remain compatibility URLs and must not be reused.
